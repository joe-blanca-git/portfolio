# 🌐 Portfólio Pessoal

Portfólio desenvolvido para apresentar projetos, habilidades, experiências e soluções digitais modernas voltadas para sistemas web, automações, inteligência artificial e aplicações para empresas e agronegócio.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap

---

# ✨ Sobre o Projeto

Este projeto foi criado com foco em:

* Design moderno e responsivo
* Navegação simples e intuitiva
* Apresentação profissional de projetos
* Performance e carregamento rápido
* Compatibilidade com dispositivos móveis
* Estrutura limpa e organizada

O site funciona como uma vitrine profissional para demonstrar soluções, projetos e tecnologias desenvolvidas.
